Limitations (read before quoting a number):
  - Small test set: 14 workbooks (4 'hard') with 6-8 questions each (93 in all); repeats are two same-session runs. One wrong answer moves one workbook's score by 12-17 points and the whole set by about 1.
  - All synthetic: Every workbook scored so far is generated by gen_workbooks.py / gen_hard.py. The real-world set (42 public workbooks) has no hand-checked questions yet, and SpreadsheetBench is unrun.
  - Prices: List prices in runner/models.py were checked against the vendors' pricing pages on 2026-10-11. Haiku 5.5 and the GPT-6 models charge more above 100,000 and 272,000 prompt tokens; the runner applies that per request. Every input token is priced as uncached. Percentages depend on the input-to-output price ratio, not the absolute level; dollars depend on both. Claude models are pinned by alias, not by dated snapshot.
  - Single turn: The API results (E16/E17) send the whole workbook and ask once. Agent mode (file on disk plus tools) ran only through the Claude CLI (E09) and is not comparable with the API runs.
  - Tokenizers: Claude and GPT count the same text differently (v0.2 sent 24-27% more input tokens than CSV on both; v0.3 sends 22% more on GPT-6 (E28); the absolute counts differ). Results are per model; nothing is pooled.
  - Scope: Claude Haiku/Sonnet in the headline; Opus and GPT models are in E16 with two repeats. No open-weight model has been run.
