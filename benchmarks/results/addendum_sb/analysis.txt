Limitations (read before quoting a number):
  - Test-set size: 28 held-out workbooks and 111 questions in this corpus, 2 repeats each. The interval resamples workbooks, so it is wide when they are few; one corpus is never pooled with the other.
  - Prices: List prices from runner/models.py as frozen, confirmed against the vendors' pricing pages on 2026-11-11. Every token is priced as uncached input or output; the billed amount (Anthropic agent turns use the prompt cache) is shown beside the metric, never in its place. Percentages depend on the input-to-output price ratio; dollars depend on the prices too.
  - One-shot against agent: A one-shot call and an agent loop spend tokens differently (the loop re-reads a growing context every turn). A win over an agent is on cost per correct answer, what a user pays; it says nothing about which reads a workbook better at equal cost.
  - Tokenizers: Claude and GPT count the same text differently, so savings differ by model; results are per model and nothing is pooled.
  - Models and date: Four models, run on one date; some model IDs have no dated snapshot. Nothing is claimed for a model not run.
